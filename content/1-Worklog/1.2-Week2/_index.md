### Week 2 Objectives:

* I studied migration as an assess–mobilize–migrate process rather than a simple data copy. The activities covered workload strategy, virtual-machine portability, heterogeneous database conversion, continuous data replication, cutover validation, and disaster recovery.
* Complete each topic through referenced study, controlled hands-on work, result verification, and resource cleanup where required.

### Week 2 Achievements:

* **Knowledge acquired:** I learned to treat migration as a governed lifecycle from discovery and strategy selection through test waves, cutover, stabilization, and retirement. I can distinguish compute-image movement, database schema conversion, initial data load, continuous replication, and disaster recovery as related but separate workstreams.

* **Practical skills:** I practiced workload classification, dependency mapping, VM image import, schema assessment, target-schema preparation, DMS endpoint and task configuration, CDC monitoring, and a recovery drill. I also defined concrete validation checks for compute, network, database, application, and recovery behavior.

* **Security, operations, and cost awareness:** The migration plan included scoped service roles, protected staging storage, restricted connectivity, measurable RTO/RPO, rollback triggers, monitoring, and cleanup. Temporary replication and recovery resources were tracked because they can create both security exposure and unnecessary cost if left unmanaged.

* **Deliverables and evidence:** The completed outputs included an application inventory, dependency map, 7-R decision matrix, migration-wave plan, VM validation record, schema-conversion assessment, DMS cutover checklist, data-validation results, disaster-recovery drill record, and post-migration action list.
