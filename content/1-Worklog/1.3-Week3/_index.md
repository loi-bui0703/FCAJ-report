### Week 3 Achievements:

* **Knowledge acquired:** I understood cloud operations as a controlled system of resource metadata, centralized administration, observable signals, automated responses, and declared infrastructure. I can explain how CDK constructs synthesize into CloudFormation and how the deployed stack becomes the expected state against which drift is evaluated.

* **Practical skills:** I applied a tagging standard, managed an instance through Systems Manager, built a CloudWatch dashboard and alarm, tested an event-driven Lambda task, authored and updated CloudFormation, detected drift, and deployed the same type of infrastructure through CDK.

* **Security, operations, and cost awareness:** The work reduced direct server access, used scoped automation permissions, documented alarm ownership, reviewed change impact before deployment, and destroyed temporary stacks after testing. Version control, change sets, rollback checks, and drift detection provided an auditable operational path.

* **Deliverables and evidence:** The completed artifacts included a tag dictionary, resource ownership view, Systems Manager execution records, monitoring dashboard, alarm-response note, Lambda execution logs, versioned CloudFormation template, change-set and drift evidence, CDK source, synthesized template, and deployment/cleanup record.
