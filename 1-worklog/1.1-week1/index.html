  • I established a safe AWS learning environment and completed the foundational service path from the Cloud Journey curriculum. The week connected identity, networking, compute, storage, databases, monitoring, and cost control instead of treating them as isolated services.
  • Complete each topic through referenced study, controlled hands-on work, result verification, and resource cleanup where required.

Week 1 Achievements:

  • Knowledge acquired: I built a connected understanding of the AWS foundation layer: IAM controls who can act, VPC controls how workloads communicate, EC2 provides compute, S3 provides object storage, RDS manages relational data, and CloudWatch supplies operational visibility. I also understood why account security and budget controls are prerequisites rather than post-deployment tasks.

  • Practical skills: I completed a working lab environment that included identity permissions, segmented networking, Linux and Windows compute, persistent storage, static content, a relational database, monitoring, and CLI-based inspection. I practiced troubleshooting with policy tests, status checks, network-path analysis, logs, metrics, and direct functional testing.

  • Security, operations, and cost awareness: I consistently applied MFA, least privilege, restricted inbound rules, private network placement for the database, resource tags, monitoring alarms, and a defined cleanup procedure. I also checked current spending before and after the lab so that technical experimentation remained cost-aware.

  • Deliverables and evidence: The week produced an account-safety checklist, IAM access matrix, VPC diagram, reusable deployment notes, CRUD validation results, CloudWatch evidence, CLI command records, and a cleanup inventory. These artifacts provided traceable evidence that each component was configured and tested rather than only reviewed theoretically.
