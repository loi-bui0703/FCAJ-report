Week 6 Worklog

Week 6 Objectives:

  • I followed the Cloud Journey modernization path from a deployed monolith to decoupled, event-driven, and serverless application patterns. The work emphasized service boundaries, API contracts, asynchronous communication, managed authentication, deployment automation, and end-to-end observability.
  • Complete each topic through referenced study, controlled hands-on work, result verification, and resource cleanup where required.

Week 6 Achievements:

  • Knowledge acquired: I learned to modernize around business capabilities and controlled interfaces rather than technology replacement alone. I can explain the tradeoffs among synchronous APIs, asynchronous queues and topics, streaming, and serverless components, including their failure and ownership models.

  • Practical skills: I assessed a monolith, extracted a service boundary, defined and tested an API contract, implemented resilient messaging, built an authenticated serverless workflow, deployed it through SAM, and investigated failures with CloudWatch and X-Ray.

  • Security, operations, and cost awareness: The design used scoped execution roles, managed authentication, input validation, idempotent processing, dead-letter handling, structured telemetry, alarms, trace correlation, and rollback evidence. I also accounted for concurrency, retries, retention, log volume, and idle-resource cleanup as cost considerations.

  • Deliverables and evidence: The completed outputs included a monolith dependency map, modernization backlog, API contract, compatibility and rollback notes, event-flow diagram, retry/DLQ policy, SAM template, serverless test cases, deployment record, dashboard and alarms, X-Ray evidence, incident note, and cleanup inventory.
